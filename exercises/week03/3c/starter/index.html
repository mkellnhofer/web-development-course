Layers of the Web

Structure, style, behaviour — one layer at a time.

Structure

HTML gives a page its structure and meaning: headings, paragraphs, lists, links. It says what each part is.

Good structure is the foundation everything else builds on — including the styling you're about to apply.

Style

CSS controls how the structure looks: colour, type, and spacing.

Tip

A consistent system beats one-off tweaks every single time.
